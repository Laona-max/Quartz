# 關於主角的工作脈絡
> 需特別說明：主角作為兒少性侵保護性社工，**同時管理多個處於不同階段的案件**——進行中的訪談與評估、已安置的定期訪視、結案後的追蹤、新接的通報。

本作的主線聚焦於其中一個案件（個案Ａ），但其他案件同時存在於主角的工作日常中。

這個案件群不是背景設定，是所有規則運作的底層條件:

* 主角的判斷壓力來自：多重案件對她有限注意力的競爭
* 主角的資源限制來自：整個案件群共享有限的安置床位、諮商時段、跨單位協作能量
* 主角的職業正當性是：累積在所有案件之上的整體資產——在某一個案件中越界，會影響她在所有其他案件中的工作能力

***

## 規則 01：司法的取證困境

| 欄位           | 內容                                                                             |
| ------------ | ------------------------------------------------------------------------------ |
| **規則內容**     | - 性侵案件（尤其是家內）本質上難以留下可被司法採認的客觀證據。<br>- 司法系統無法僅憑陳述定罪，必須依賴可證明的證據。                 |
| **運作機制**     | - 這類案件發生時高度隱密、高度私人化。<br>- 創傷經驗的取證本身也比財產損失或肢體傷害更困難。這不是司法失職，是案件本質與司法認識方式之間的根本落差。 |
| **對玩家行動的影響** | - 玩家無法透過「找到決定性證據」來推進案件。<br>- 所有證據都是片段的、可被質疑的、需要多方交叉驗證的。                        |
| **扣合敘事支柱**   | - 支柱 3（制度運作良好卻仍傷人）                                                             |

***

## 規則 02：正式程序的雙面性

| 欄位           | 內容                                                                      |
| ------------ | ----------------------------------------------------------------------- |
| **規則內容**     | - 正式程序要求明確分類與穩定陳述。<br>- 程序同時負擔兩個任務：保護個案，以及保護嫌疑犯不被預先定罪。                  |
| **運作機制**     | - 程序要求穩定一致的陳述，但個案經驗往往先天帶有模糊與反覆。<br>- 程序的正當性（保護人權）與程序的代價（二次傷害）是同一套機制的兩面。 |
| **對玩家行動的影響** | - 玩家每推進一步程序，都在迫使個案重新陳述、重新分類、重新被檢驗。<br>- 推進本身就是消耗。                       |
| **扣合敘事支柱**   | - 支柱 3（制度運作良好卻仍傷人）                                                      |

***

## 規則 03：法定通報與時限壓力

| 欄位           | 內容                                                          |
| ------------ | ----------------------------------------------------------- |
| **規則內容**     | - 兒少保護案件依法有通報義務且有時限。<br>- 通報一旦啟動即不可逆。                       |
| **運作機制**     | - 時限壓力是制度為了防止案件被延誤或被掩蓋而設計的強制推進機制。<br>- 不通報是失職，通報後流程也無法完全可控。 |
| **對玩家行動的影響** | - 玩家無法無限期觀察後才行動。<br>- 所有訪談、判斷、協調都受時間約束。                     |
| **扣合敘事支柱**   | - 支柱 3（制度運作良好卻仍傷人）                                          |

***

## 規則 04：校園的通報節奏與自保邏輯

| 欄位           | 內容                                                                                                                                                   |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **規則內容**     | - 教師、輔導老師、護理師等校園工作者依法是責任通報人，知悉兒少疑似遭受傷害時必須在 24 小時內通報。<br>- 通報啟動後，個案在校園的處境也會被改變——她不再只是學生，是「案件中的孩子」。                                                    |
| **運作機制**     | - 通報義務不是校方的選擇，是法律對校方的要求。<br>- 即便老師知道通報會改變個案在學校的處境，她也沒有不通報的選項。<br>- **這份要求保護了一些孩子，也讓某些孩子失去了她們本來的避難空間**——當學校原本是個案唯一還能感到安全的地方時，通報這個動作本身就會啟動一連串她無法承受的後果。 |
| **對玩家行動的影響** | - 玩家無法把校方當作對抗的目標——校方是執行者，不是決策者。<br>- 但校方的處境會影響個案在校園裡的日常，玩家需要思考如何在不傷害個案校園生活的情況下推進案件。                                                                  |
| **扣合敘事支柱**   | - 支柱 2（個案的日常生活是最高位階）<br>- 支柱 3（制度運作良好卻仍傷人）                                                                                                           |

***

## 規則 05：社工的專業限制

| 欄位           | 內容                                                               |
| ------------ | ---------------------------------------------------------------- |
| **規則內容**     | - 訪談與詢問方式受專業規範限制：<br>    - 不得引導性提問<br>    - 不得逼問<br>    - 不得誘導暗示 |
| **運作機制**     | - 專業規範保護個案不受二次傷害，同時維持陳述的證據效力。<br>- 違反規範既傷害個案，也讓案件在司法上失去證據力。      |
| **對玩家行動的影響** | - 玩家在訪談中的選項受限——直接、尖銳、情緒化的追問往往是「違規選項」，雖然短期有效，但會削弱案件正當性或傷害個案。      |
| **扣合敘事支柱**   | - 支柱 2（個案的日常生活是最高位階）<br>- 支柱 4（靠近是判斷的必要條件，也是判斷會被檢驗的位置）           |

***

## 規則 06：匱乏的社會福利資源

| 欄位           | 內容                                                                |
| ------------ | ----------------------------------------------------------------- |
| **規則內容**     | - 安置床位、醫療資源、諮商時段、跨單位協作能量都是有限的。<br>- 主角不能「調度所有最好的資源」給一個個案。         |
| **運作機制**     | - 資源匱乏是結構性的，不是單次事件的問題。<br>- 即便主角判斷個案需要某種資源，也可能因為沒有床位、沒有時段而無法取得。   |
| **對玩家行動的影響** | - 玩家被迫在「安全」與「穩定」之間取捨——安置能確保安全但切斷依附，留在原環境保留穩定但風險未解除。<br>- 沒有兩全的選項。 |
| **扣合敘事支柱**   | - 支柱 1（正義是有優先次序的）<br>- 支柱 3（制度運作良好卻仍傷人）                           |

***

## 規則 07：話語權的壟斷與衝突

| 欄位           | 內容                                                                |
| ------------ | ----------------------------------------------------------------- |
| **規則內容**     | - 校方、家屬、警檢、醫療、社福各自掌握案件的一部分定義權，對同一事件往往有不同的描述、不同的優先順序。              |
| **運作機制**     | - 沒有任何單一節點能獨自定義案件的全貌。<br>- 每個節點都從自己的專業角度、責任範圍、利害關係出發，給出「自己版本的真相」。 |
| **對玩家行動的影響** | - 玩家必須在多個相互衝突的版本之間推進工作，不能單方面宣告自己版本的真相。<br>- 協調與說服本身就是重要的玩法內容。     |
| **扣合敘事支柱**   | - 支柱 3（制度運作良好卻仍傷人）                                                |

***

## 規則 08：社工身份的正當性是有限資源

| 欄位           | 內容                                                                       |
| ------------ | ------------------------------------------------------------------------ |
| **規則內容**     | - 主角作為社工的身份正當性，建立在程序合規、專業界線、與各單位的信任關係之上。<br>- 這份正當性每一次使用都會被消耗，一旦失去就難以恢復。 |
| **運作機制**     | - 越界行動短期內可能取得個案信任、推進案件。<br>- 但長期會讓其他單位不再配合、讓案件失去正當性、讓主角後續的所有判斷都站不住腳。     |
| **對玩家行動的影響** | - 玩家的每一次越界行動都會累積成本，這個成本在當下可能看不見，但會在後期以「失去某個資源」「失去某個單位的配合」的形式浮現。          |
| **扣合敘事支柱**   | - 支柱 4（靠近是判斷的必要條件，也是判斷會被檢驗的位置）                                           |

***

## 規則 09：家庭作為不宜外力介入的空間

| 欄位           | 內容                                                                               |
| ------------ | -------------------------------------------------------------------------------- |
| **規則內容**     | - 在東亞文化脈絡下，家庭內部的事被視為「家醜」。<br>- 羞恥感不僅屬於受害者，也屬於整個家庭。                               |
| **運作機制**     | - 這使傷害、照顧、依附、羞恥與沉默被綁在一起。<br>- 任何一方的揭露都被視為對整個家庭的背叛。<br>- 沉默不是個案的選擇，是她被文化結構分配到的位置。 |
| **對玩家行動的影響** | - 玩家與家庭的互動不是單純的合作或對抗——家庭成員即便知道真相，也可能主動壓制真相浮現。<br>- 揭露本身會引發家庭的集體反彈。               |
| **扣合敘事支柱**   | - 支柱 2（個案的日常生活是最高位階）                                                             |

***

## 規則 10：依附的雙重性

| 欄位           | 內容                                                                                 |
| ------------ | ---------------------------------------------------------------------------------- |
| **規則內容**     | - 兒少對加害者或家庭成員可能仍有情感依附。<br>- 加害與照顧可能來自同一個人。                                         |
| **運作機制**     | - 「離開」不等於立刻得救——離開也意味著失去她原本依附的世界、熟悉的日常、甚至身份認同。<br>- 很多最難處理的問題，不來自純粹惡意，而來自親密關係內部的失衡。 |
| **對玩家行動的影響** | - 玩家不能假設「把個案從加害者身邊帶走＝拯救個案」。<br>- 處置的正確性必須考量個案的依附結構，不只是外部安全性。                       |
| **扣合敘事支柱**   | - 支柱 2（個案的日常生活是最高位階）                                                               |

***

## 規則 11：輿論的雙刃

| 欄位           | 內容                                                                      |
| ------------ | ----------------------------------------------------------------------- |
| **規則內容**     | - 社會輿論傾向要求事件被快速定義、快速表態，但真實個案往往無法立刻說清。                                   |
| **運作機制**     | - 一旦事件外溢，輿論既可能推動制度介入，也可能製造新的羞恥、標籤與壓力。<br>- 輿論的力量在東亞社會常比正式制度更直接作用於個案的日常。 |
| **對玩家行動的影響** | - 玩家的某些行動會造成事件曝光風險。<br>- 曝光不必然是壞事——有時能推動停滯的案件——但也可能帶來個案無法承受的二次傷害。       |
| **扣合敘事支柱**   | - 支柱 3（制度運作良好卻仍傷人）                                                      |
