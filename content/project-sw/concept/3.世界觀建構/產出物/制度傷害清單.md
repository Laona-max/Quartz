## 傷害 01：通報的傷害

| 欄位            | 內容                                                                                                                    |
| ------------- | --------------------------------------------------------------------------------------------------------------------- |
| **傷害機制**      | - 通報是不可逆的行動。<br>- 一通報，家庭的私領域就變成制度可介入的對象；通報後的流程也無法完全可控——個案無法預見自己之後會經歷什麼，家庭關係也會因此被重新定義。<br>- 不通報是失職，通報又可能讓個案失去對事情節奏的掌控。 |
| **落在誰身上**     | - 主要落在個案身上<br>    - 失去節奏掌控<br>	- 被推入未知流程<br>- 次要落在家庭成員身上<br>    - 關係被重新定義                                             |
| **可能的劇情呈現形態** | - 主角在是否通報之間掙扎的場景<br>- 通報後個案第一次面對制度流程（警檢約談、醫院採證）的場景<br>- 個案事後對主角說「我不知道會變成這樣」的場景<br>- 家屬在通報後的反應場景（憤怒、否認、切割）             |
| **扣合敘事支柱**    | - 支柱 3（制度運作良好卻仍傷人）<br>- 支柱 5（玩家原本的正義直覺）                                                                               |

## 傷害 02：重複敘述的傷害

| 欄位            | 內容                                                                                                           |
| ------------- | ------------------------------------------------------------------------------------------------------------ |
| **傷害機制**      | - 每個單位都需要資訊——警方要、檢方要、社工要、醫院要、學校要。<br>- 個案每向一個單位重述一次，都可能更疲乏、更封閉、更混亂。<br>- 重述不是中性的資訊傳遞，它會讓個案重新經歷一次。            |
| **落在誰身上**     | - 主要落在個案身上<br>    - 反覆揭露創傷<br>- 次要也落在主角身上<br>    - 目睹個案被反覆消耗卻無法完全避免                                          |
| **可能的劇情呈現形態** | - 個案在第 N 次敘述中突然無法說話或說錯細節的場景<br>- 不同單位因為彼此不信任而要求個案再說一次的場景<br>- 主角嘗試在單位之間傳遞紀錄以減少重述、卻遭拒絕的場景<br>- 個案在重述後的退縮或情緒反應 |
| **扣合敘事支柱**    | - 支柱 2（個案的日常生活是最高位階）<br>- 支柱 3（制度運作良好卻仍傷人）                                                                   |

## 傷害 03：證明的傷害

| 欄位            | 內容                                                                                                                    |
| ------------- | --------------------------------------------------------------------------------------------------------------------- |
| **傷害機制**      | - 制度需要穩定一致的說法才能據以行動；創傷卻讓敘述本身變得困難——記憶可能是跳躍的、時序可能是錯亂的、細節可能隨時間改變。<br>- 個案在「證明自己」的過程中，被迫用一種不屬於她的語言，講述一段她還無法完整消化的經驗。       |
| **落在誰身上**     | - 個案<br>    - 被迫用制度語言重新組裝自己的經驗                                                                                        |
| **可能的劇情呈現形態** | - 個案的陳述在不同時間點出現矛盾、被警檢質疑可信度的場景<br>- 個案開始懷疑自己的記憶是否正確的場景<br>- 律師教個案「這樣說比較有利」時，個案陷入沈默的場景<br>- 個案的陳述被要求「再具體一點」、「再清楚一點」時的崩潰 |
| **扣合敘事支柱**    | - 支柱 2（個案的日常生活是最高位階）<br>- 支柱 3（制度運作良好卻仍傷人）                                                                            |

## 傷害 04：保護處置的傷害

| 欄位            | 內容                                                                                                                 |
| :------------ | ------------------------------------------------------------------------------------------------------------------ |
| **傷害機制**      | - 帶走個案不等於完成保護。<br>- 保護同時也可能拆掉她原本仍依附的世界——熟悉的作息、重要的人際關係、甚至身份認同。<br>- 她獲得安全的同時，也失去她原本認識的生活。<br>- 這份失去不會因為新環境更安全而自動消化。 |
| **落在誰身上**     | - 主要落在個案身上<br>    - 失去依附的世界<br>- 次要落在家庭成員身上<br>    - 某些照顧者可能也失去個案                                                  |
| **可能的劇情呈現形態** | - 個案進入安置機構後的失語或退縮場景<br>- 個案思念加害者或家庭成員的場景（這份思念本身就是傷害的一部分）<br>- 個案問「我什麼時候可以回家」時，主角無法回答的場景<br>- 個案在新環境中無法建立信任、反覆試探的場景 |
| **扣合敘事支柱**    | - 支柱 2（個案的日常生活是最高位階）<br>- 支柱 1（正義是有優先次序的）                                                                          |

***

## 傷害 05：協作斷裂的傷害

| 欄位            | 內容                                                                                                                     |
| ------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **傷害機制**      | - 校方、社工、警檢、醫療各有自己的語言、責任範圍、優先順序。<br>- 個案容易變成被來回搬運的人，而不是被統一承接的人。<br>- 每個單位都盡到了自己的責任，但個案感受到的是被切成碎片、被反覆轉介、沒有一個人真正負責她的完整處境。 |
| **落在誰身上**     | - 主要落在個案身上<br>    - 失去被完整對待的感覺<br>- 次要落在主角身上<br>	- 成為各單位之間的轉譯者與協調者                                                     |
| **可能的劇情呈現形態** | - 個案在跨單位會議中被各方討論、卻沒有人問她想法的場景<br>- 不同單位給出矛盾指示、個案不知道該聽誰的場景<br>- 主角被迫在單位之間反覆解釋、傳話、補漏的場景<br>- 個案說「你們每個人說的都不一樣」時的失望         |
| **扣合敘事支柱**    | - 支柱 3（制度運作良好卻仍傷人）                                                                                                     |

## 傷害 06：保密與曝光的傷害

| 欄位            | 內容                                                                                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **傷害機制**      | - 制度強調保密，但案件一旦進入校園、家庭與地方網絡，就會留下社會性痕跡。<br>- 即使程序上沒有外洩，個案的日常處境仍會發生改變——老師看她的眼神不同了、同學開始竊竊私語、親戚開始「特別關心」。<br>- 保密是程序上的，曝光是社會性的，兩者不在同一個層次。                    |
| **落在誰身上**     | - 主要落在個案身上<br>    - 日常處境的改變<br>- 次要落在家庭身上<br>    - 社區網絡的評價                                                                                             |
| **可能的劇情呈現形態** | - 個案回到學校後發現同學態度改變的場景<br>    - 同學知道後不敢再用以前的方式跟她相處<br>- 親戚或鄰居「關心」的場景<br>    - 表面善意，實際是二次傷害<br>- 個案希望被當成「正常人」，卻處處感受到被特殊對待的場景<br>- 主角發現個案的處境已經在社區中被低聲討論的場景 |
| **扣合敘事支柱**    | - 支柱 2（個案的日常生活是最高位階）<br>- 支柱 3（制度運作良好卻仍傷人）                                                                                                             |

## 傷害 07：語言不相容的傷害

| 欄位            | 內容                                                                                                                   |
| ------------- | -------------------------------------------------------------------------------------------------------------------- |
| **傷害機制**      | - 制度需要明確的「誰對誰做了什麼」；家庭內部的傷害往往是模糊的、反覆的、滲透在日常細節裡的。<br>- 個案被迫學會用一種不屬於她的語言，把她經驗過的東西切成制度能處理的形狀——但那些無法被切分的部分，就變成沒有名字的殘餘。    |
| **落在誰身上**     | - 個案<br>    - 經驗被強制重新編碼                                                                                              |
| **可能的劇情呈現形態** | - 個案想說某件事，但找不到符合制度分類的字眼的場景<br>- 個案說「他對我很好，但也會……」這種複雜句，被要求「只說壞的那部分」的場景<br>- 個案在問卷或筆錄上勾選「是／否」時的遲疑<br>- 個案寧可沈默也不願被誤解的場景 |
| **扣合敘事支柱**    | - 支柱 2（個案的日常生活是最高位階）<br>- 支柱 3（制度運作良好卻仍傷人）                                                                           |
